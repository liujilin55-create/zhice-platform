# 学校目录与版式登记

本模块管理用户提供的福建农林大学目录、通知和获奖 PPT 参考的来源及核验状态。初始真实数据为空，不自行联网补充比赛、校内等级或获奖材料。

- `/admin` →「学校竞赛目录 / 获奖 PPT 版式 / 来源核验」：JSON/CSV 导入预览、提交、逐项核验、版式登记。
- `GET /api/catalog`：浏览器需要的版本化目录、可追溯模板配置。客户端通过 `services.ts` 的 schema 边界读取。
- `GET/POST /api/admin/catalog`：必须使用现有管理员会话。preview/import/review/template 操作；multipart 支持 PPTX 样式提取与登记。
- 存储：`data/campus-catalog.json`，原子写入，进程内串行变更，审核追加日志。适用于现有单实例本地部署；多实例部署需换事务数据库。

比赛内容版本由规范名称 + 学年度确定 editionId，内容哈希确定不可变 competitionId。改动内容生成新 ID；历史 ID 持续可解析。项目维持原 competitionId，不自动迁移。目录核验不替代评分原句核验，后者仍逐字绑定当前比赛与赛道的来源缓存。

PPTX 只在内存中读取设计元数据，返回归一化自有规则、文件 SHA256 和页数。原始文件、文本、图片、Logo、图表数据和整页不会落盘或分发。预览使用平台自绘 SVG。只有来源和衍生授权分别确认、且当前未过期/冲突的配置才能作为正式模板。渲染前后都会重新检查授权，导出历史保留 templateId、版本、来源及授权说明。

现有平台原创模板始终可用；来源登记不明确的配置只展示为参考风格。图表仅从已确认原文中抽取具有相同单位的明确数值，生成原生 PowerPoint 图表和嵌入工作簿；素材不足时保留文字，不补造数据。
