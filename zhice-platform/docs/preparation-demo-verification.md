# 政和科技小院材料准备演示与验证记录

验证日期：2026-11-04。本地演示入口：http://localhost:3000/?view=journey

## 演示路径

1. 点击“开始政和演示”；已有演示项目时显示“继续政和演示”。演示项目独立保存，原有项目可以切回。
2. 确认福建农林大学、材料工程学院、木材科学与工程专业，以及学生提供的政和县科技小院合作背景。支持“还没有项目”和“已有想法 / 项目”两个入口。
3. 完成产业对接、原料、设备与导师、真实需求、团队投入五项资源访谈。每题可主动使用带有“演示假设”的示例回答，企业与实验条件不会自动变成事实。
4. 比较不同赛事的候选及推荐依据，核对校内认定、当届资格和赛道后确认备赛选择。保留完整学校目录查询入口。
5. 比较缓冲包装、育苗容器、功能板材三个方向，演示采用“竹加工剩余物缓冲包装材料的设计与应用验证”。确认定位后检索论文、登记有来源的案例。
6. 把项目定位、资源与引用资料带入计划书问卷，逐章生成并直接在网页修改、确认和导出 Word。
7. 从已确认的计划书内容生成 PPT 大纲，人工确认后生成可编辑 PPTX。缺少的材料保留补充标记。

## 核验行为

- 页面中的“待核验”统一配有“去核验”链接和“确认核验”按钮。有来源时打开来源；没有来源时进入相关资料页或核验工作台的对应条目。
- 确认弹窗记录结论、具体结果、来源、核验人和说明。默认仍为“暂无法确认”，支持发现不符、修改记录和撤销。
- 记录保存在当前浏览器，关联项目、比赛版本和具体内容。内容修改后不会继承旧内容的通过记录。
- 学生个人确认不会直接替代官方评分原文、报名资格或学校认定核验。
- 修改选题、资源回答、参赛画像或引用资料后，已有材料提示复核；更新问卷保留已有章节和历史版本。旧定位的 PPT 生成、确认和导出受保护。
