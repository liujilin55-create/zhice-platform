# 第四阶段：学校目录、来源核验与获奖版式

当前结论：导入、核验、推荐筛选与 PPT 模板连接已经实现。用户表示材料尚未整理，因此**未导入任何真实学校目录或获奖 PPT**。运行时真实目录为空，原有演示比赛仍明确标记为演示；四套平台原创模板继续保留。

## 使用入口

打开 `http://localhost:3000/admin`，用现有管理员账号登录，点击「学校竞赛目录 / 获奖 PPT 版式 / 来源核验」。

1. 下载空白 CSV 或 JSON 字段示例，按照学校提供的原始材料填写；示例的空名称必须替换，不能直接作为真实目录导入。
2. 选择 JSON/CSV，点击「校验并预览」，检查重复、学年度、等级冲突、来源缺失与截止时间提示，再确认导入。
3. 比赛适用性、校内等级和官方比赛链接分别核验。每项填写依据及备注，保留时间与完整日志。导入文件自己声明 `verificationStatus: verified` 不会被采纳。
4. 用户在比赛推荐中筛选和选择比赛。项目绑定具体目录内容版本；目录之后更新，不改变已有项目的比赛、计划书、报告和任务上下文。
5. 获奖版式登记填写来源比赛、年份、赛道、来源文件/链接、权限与授权依据。可上传 ≤20 MB 的 `.pptx` 统计设计规律，也可登记有来源的自有配置。
6. 来源与授权分别确认后，在 PPT 页使用按比赛/赛道推荐的模板，或手动选择。未确认/过期/冲突的登记只显示参考风格。服务器同样禁止将其用于正式导出。

## 目录字段

JSON 为记录数组；CSV 支持下列中文列名及对应英文键。CSV 多值字段用半角或全角分号分隔，支持 BOM、引号、逗号和多行单元格。

| 中文列名 | JSON 键 | 约定 |
| --- | --- | --- |
| 比赛名称 | name | 必填；不得把 AI 编造的信息当事实 |
| 学年度 | academicYear | 必填，如 `2026-2027`；必须连续 |
| 外部赛事级别 | externalLevel | 未知填 null/空白 |
| 校内认定等级 | campusRecognitionLevel | 严格照录来源；不预置 A+/A 权重 |
| 适用学院/专业/年级 | colleges / majors / grades | JSON 字符串数组；未知用空数组 |
| 参赛赛道 | tracks | 同上；缺失时显示「赛道待核验」 |
| 校内报名方式 | campusRegistration | 文字或 null |
| 校内截止时间 | campusDeadline | ISO 带时区，如 `2026-12-01T23:59:59+08:00`；未知为 null |
| 官方比赛链接 | officialUrl | HTTP(S) URL 或 null |
| 校内通知链接 | campusUrl | HTTP(S) URL 或 null |
| 来源文件名/页码 | sourceFile / sourcePage | 文件名和正整数页码，未知为 null |
| 来源原文 | sourceText | 可选，逐字提供通知原文，用于比赛要求分析；缺失时提示上传原文 |

其他可选 JSON 字段：`organizer`、`keywords`、`skills`、`resources`、`mentors`、`goals`、`teamMin`、`teamMax`、`weeklyHours`、`budget`、`submissionMaterials`。缺失值不生成官方事实。`lastVerified`、`verificationStatus` 和审计日志由后台核验操作产生。

没有校内通知链接、也没有带页码的来源文件时，记录无法标记已确认；缺少校内等级或官方链接时，对应核验同样被拒绝。等级不明不计认定加分。已核验且适用的校内认定加 14 分；学生目标涉及认定、学分、获奖等再加 8 分；这是资料确定性与目标匹配权重，不代表学校等级之间的排名。

目录中的原文作为校内来源保留文件及页码，评分条款仍要求用户逐字摘录后确认；目录核验不会自动把某段文字变成评分标准。没有原文时不根据比赛名称生成官方要求，也不任意抓取未提供的外部地址。

## 模板边界

模板登记包含来源、年份、赛道、权限、适用场景、11 类布局、配色、字体、图表类型、封面/结尾布局、平台自绘预览、核验状态与日志。11 类页面为封面、目录、问题、数据、方案、流程、架构、商业模式、团队、计划、结尾。

上传分析仅在内存中统计颜色、字体、字号、分栏倾向、首尾对齐和图表类型，再归一化到平台原创布局。不会保存或输出原作品文本、图片、Logo、原图表数据、原始坐标或整页。仅登记来源文件名、SHA256、页数与自有配置；没有原始获奖文件下载地址。

权限为 `unknown` 或 `reference_only` 时不能确认衍生使用权；`derivation_allowed` 或 `owned` 还需明确授权依据、说明以及人工来源/权限确认。禁止仅靠前端修改 templateId 绕过授权。平台内置原创模板不宣称来自获奖作品。

导出的 PPTX 包含原生文字、形状及演讲者备注。具有同单位且已确认的单数值事实可以生成可编辑图表（含嵌入 XLSX），其他情况保留文字，不补造图表数据。导出历史记录 templateId、配置版本、来源和授权说明；文档版本与项目绑定继续沿用第三阶段约束。
